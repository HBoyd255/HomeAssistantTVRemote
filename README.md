# Home Assistant TV Remote

A simple project that combines the home-assistant-integration library with the
IRremoteESP8266 library to allow the control of a Samsung TV through Home
Assistant.

This project is designed around the
[ESP_IR_TR_WIFI](https://www.aliexpress.com/s/wiki-ssr/article/esp-ir-tr-wifi)
